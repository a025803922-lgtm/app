# מיקרופון מההגה — הוראות התקנה

האפליקציה מחברת את כפתור העוזר שבהגה למיקרופון הצף של Offline Assistant. היא מיועדת למערכת Topway TS10 עם Android.

## התקנה והפעלה

1. התקינו את קובץ ה־APK. אם Android חוסם את ההתקנה, אשרו התקנה ממקור זה בהודעה שמופיעה.
2. פתחו את **מיקרופון מההגה**.
3. פתחו את הגדרות **נגישות** של Android, בחרו בשירות **מיקרופון מההגה**, הפעילו אותו ואשרו את הודעת Android.
4. חזרו לעוזר. לחיצה על כפתור העוזר שבהגה אמורה להפעיל את ההאזנה ולהשמיע צליל קצר.
5. אם כפתור ההגה מוגדר לפתוח את העוזר הדיגיטלי, בחרו **מיקרופון מההגה** בהגדרות: **אפליקציות ← אפליקציות ברירת מחדל ← אפליקציית עוזר דיגיטלי**. שמות התפריטים עשויים להשתנות בין מערכות.

## כיבוי והדלקה של הרכב (ACC)

במערכת TS10 כיבוי הרכב עשוי להעביר את היחידה למצב שינה עמוקה, בלי להפעיל מחדש את Android. אחרי החזרת מתח ה־ACC, האפליקציה מנסה לשחזר את שירות הנגישות אם המערכת כיבתה אותו.

כדי ששחזור זה יעבוד במכשיר שמאפס את שירותי הנגישות, דרושה הרשאת מערכת חד־פעמית. אין צורך בה בדרך כלל, ו־Android לא מאפשרת לאפליקציה להעניק לעצמה הרשאה זו:

1. הפעילו ADB במערכת וחברו אליה ממחשב.
2. במחשב הריצו פעם אחת:
   `adb shell pm grant com.example.wheelmic android.permission.WRITE_SECURE_SETTINGS`
3. פתחו את שירות **מיקרופון מההגה** בהגדרות הנגישות והפעילו את האפשרות **שחזור הנגישות לאחר הפעלה מחדש**.

האפליקציה אינה מפעילה ADB בעצמה. אם שירות הנגישות נשאר פעיל גם אחרי כיבוי והדלקה של הרכב, אין צורך להעניק את ההרשאה הזו.
